# Third-Party Risk Assessment

A public-source Notion review for a fictional SaaS buyer. Thirty questions separate advertised capability from verified operation.

**[Open the interactive case study](https://shassanahmed.space/projects/vendor-risk/)** · [Read the report](report.md) · [Records CSV](records.csv) · [Records JSON](records.json)

## Reproduce the review

1. Read report.md and methodology.md.
2. Select a record in records.csv and follow its evidence references.
3. Inspect the supporting fixtures and collection guidance, where provided.
4. Run the repository suite checks: `node suite-tests.mjs`.
5. Describe evidence gaps before discussing a conclusion.
