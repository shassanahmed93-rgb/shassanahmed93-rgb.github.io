GRC Sentinel

A GRC application for organizing security evidence, assessments, and remediation across frameworks.

How the workflow fits together

  1. Collect evidence that supports a control or assessment.
  2. Use assessment rules to identify gaps.
  3. Record a risk treatment or remediation action and track it.

The authenticated demo is a local test environment. This page is a public project walkthrough.
