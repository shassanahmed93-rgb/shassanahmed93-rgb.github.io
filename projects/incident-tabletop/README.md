## Reproduce the review

1. Read report.md and methodology.md.
2. Select a record in records.csv and follow its evidence references.
3. Inspect the supporting fixtures and collection guidance, where provided.
4. Run the repository suite checks: `node suite-tests.mjs`.
5. Describe evidence gaps before discussing a conclusion.
